# ⚖️ AI Legal Aid Agent

An interactive, AI-powered legal guidance web application integrated with **IBM WatsonX Orchestrate**. This platform provides 24/7, plain-language legal aid, contract reviews, rights advisory, and document drafting guidance.

---

## 🌟 Key Features

*   **IBM WatsonX Orchestrate Embedded Widget:** Seamless web-chat interface powered by enterprise-grade AI models.
*   **Animated Counter & Stats:** Dynamic performance metrics triggered via `IntersectionObserver`.
*   **Scroll-Reveal Animations:** Smooth entry transitions for features, steps, and testimonials.
*   **Responsive Design:** Optimized for desktop, tablet, and mobile browsers with a dedicated collapsible mobile menu.
*   **Legal Disclaimer Banner:** Clear, built-in notice regarding the distinction between general information and professional legal counsel.
